1. Ringkasan Arsitektur

Tenun Nusantara adalah platform web gamifikasi edukatif untuk memetakan minat-bakat anak (7–14 tahun) lewat petualangan di 5 pulau, dengan pendamping AI NALA. Aplikasi dibangun di atas Next.js 14 (App Router), menggunakan Supabase untuk backend, dan Google Gemini untuk kecerdasan runtime.

✍️ Cara aplikasi dibangun

  • 🎨 Desain & aset: wireframe/prototype di Figma; aset game dihasilkan dengan bantuan Gemini & Nano Banana.
  • 💻 Kode: ditulis/direfaktor dengan bantuan DeepSeek, Claude, dan Qwen.
  • ⚙️ Runtime AI: NALA ditenagai Google Gemini via Vercel AI SDK (dengan fallback statis).

2. Tech Stack

Frontend

Next.js 14 (App Router), React 18, TypeScript (strict), TailwindCSS, Zustand, Framer Motion, lucide-react

Backend & Data

Supabase (PostgreSQL + Auth + Storage), API Routes (App Router), Row Level Security

AI / LLM

Vercel AI SDK (ai v3), @ai-sdk/google, Google Gemini (runtime NALA)

Audio / TTS

msedge-tts (Edge TTS id-ID-GadisNeural), Web Speech API (fallback)

Laporan / Visual

recharts (radar & grafik), jspdf + html2canvas (unduh PDF)

Utility

zod (validasi), react-hook-form, date-fns, tailwind-merge, inkjs (narasi)

3. Arsitektur & Struktur Proyek

Next.js App Router dengan route groups untuk memisahkan area per peran.

src/
├─ app/
│  ├─ (marketing)/   # Landing page
│  ├─ (auth)/        # Login & role-selection
│  ├─ (student)/     # map, island, refleksi, report, profil
│  ├─ (parent)/      # home
│  ├─ (teacher)/     # dashboard (ringkasan, sebaran, siswa, laporan)
│  ├─ api/           # ai, tts, reports, telemetry
│  ├─ dokumentasi-pengguna/  # Panduan pengguna (3 peran)
│  └─ dokumentasi-teknis/    # Dokumen ini
├─ components/   (game, layout, map, landing, report, teacher, ui, dashboard)
├─ config/
│  ├─ islands.json   # KONTEN pulau (data-driven) — bisa diedit tanpa kode
│  └─ islands.ts, asset-paths.ts, site.ts, orientation.ts
├─ hooks/            # use-nala, use-tts, use-voice-input, use-sound, ...
├─ lib/
│  ├─ ai/            # gemini, nala-agent, prompts, report, generate
│  ├─ scoring/       # engine (8 dimensi), evidence-rules, triangulation
│  ├─ session/       # session.ts, game-store.ts (persistensi + resume)
│  ├─ supabase/      # client, server, service, sync
│  └─ sound/ telemetry/ teacher/ report/ utils/
├─ stores/           # zustand (auth, story, student)
└─ types/            # game, story, telemetry, user

Pendekatan data-driven: konten pulau (minigame, asesmen, refleksi, dialog NALA) di islands.json dapat diubah tanpa menyentuh kode.

4. AI yang Digunakan

A. AI Runtime (di dalam aplikasi)

Google Gemini — via Vercel AI SDK (@ai-sdk/google)

NALA: kawan petualang AI. Narasi adaptif, petunjuk, refleksi, dan laporan Peta Bakat.

gemini-2.5-flash (default + fallback)

Model utama runtime; fallback gemini-1.5-flash & gemini-2.0-flash. Bisa diatur via env GEMINI_MODEL.

Fallback statis (lib/ai/prompts.ts)

Balasan NALA otomatis bila API key Gemini tidak tersedia.

7. Suara NALA (Text-to-Speech)

1. Edge TTS (utama)

via API route /api/tts (msedge-tts), suara id-ID-GadisNeural — gratis & natural.

2. Web Speech API (fallback)

speechSynthesis dengan suara perempuan/anak berbahasa Indonesia bila Edge gagal.

Input suara

Web Speech API (use-voice-input) untuk menjawab refleksi dengan suara; ada mute global.

8. Sistem Laporan

📊 Peta Bakat (Siswa)

Radar 8 dimensi, bakat dominan, lencana, pesan NALA. Terbuka setelah 5 pulau selesai.

🏫 Dashboard Guru

Ringkasan kelas, sebaran karakter, daftar siswa, laporan akademik, pengaturan kelas (kode kelas).

👨‍👩‍👧 Laporan Orang Tua

Masukkan kode game anak (TN-XXXXXX) untuk melihat kemajuan & Peta Bakat; laporan bisa diunduh (jspdf).
